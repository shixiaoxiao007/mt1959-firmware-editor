\# LG MT1959 固件编辑器 v1.0

\## 功能概览

\### 核心功能

\- ✅ \*\*双视图模式\*\*

&#x20; - 物理视图：按固件物理表结构显示（BD-XL, 15B-A/B/C/D 等）

&#x20; - 逻辑视图：按介质类型分组显示（BD-R SL 25GB, BD-R DL 50GB 等）

\- ✅ \*\*记录管理\*\*

&#x20; - 添加：在空槽位添加新 MID 记录

&#x20; - 编辑：修改 MID 和参数

&#x20; - 删除：删除记录（变为全 0xFF 空槽）

&#x20; - 复制：在表之间复制记录（支持不同步长自动适配）

\- ✅ \*\*WSR 区域替换\*\*

&#x20; - 替换自其他固件：从其他固件导入 WSR 数据

&#x20; - 替换到其他固件：将当前 WSR 导出到其他固件

\- ✅ \*\*文件操作\*\*

&#x20; - 打开固件：自动检测 WSR 区域和压缩格式

&#x20; - 保存：原地保存或另存为

&#x20; - 自动备份：原地保存时生成 .bak 文件

\### 安全特性

\- 压缩算法验证：只允许编辑可逐字节复现的固件

\- 修改标记：窗口标题显示 `\*` 表示有未保存修改

\- 关闭确认：有未保存修改时弹出保存提示

\- 备份保护：原地保存时自动备份原文件

\### 记录类型

\- \*\*有效记录\*\*（绿色）：包含 MID 和参数的正常记录

\- \*\*保留槽位\*\*（黄色）：MID=0xFF 但预设参数，留给 OEM 填充

\- \*\*空槽位\*\*（灰色）：全 0xFF，可用于添加新记录

\- \*\*全零记录\*\*（橙色）：全 0x00，异常状态

\- \*\*无效记录\*\*（红色）：格式错误

复制：选中记录 → 点击"复制到..." → 选择目标表和槽位

4\. 保存

物理表

\[12-13]: BD-RE XL

15B-A (0x3E00-0x3FEC, 15字节): BD-R SL 25GB

15B-B (0x3FED-0x40FF, 15字节): BD-R SL 25GB + 保留槽位

15B-C (0x4100-0x41D4, 15字节): BD-R DL 50GB

15B-D (0x41D5-0x4634, 15字节): BD-RE SL/DL + 保留槽位

技术细节

压缩算法

使用 LZ77 变体：



窗口大小：4096 字节

最大匹配长度：18 字节

匹配策略：最长+最远优先

控制字节继承：后续块重用前一个控制字节

文件格式

WSR 标记：OOB WSR 位于压缩数据前一字节

结束标记：连续 0x40 字节的 0xFF

压缩数据边界自动检测
