# LG MT1959 固件编辑器

LG 光驱固件 WSR（Write Strategy Region）区域编辑工具，支持对 BD-R/BD-RE/BD-XL 等蓝光介质记录进行查看、新增、编辑和删除操作。

## 项目简介

本工具专为 LG MT1959 系列光驱固件设计，能够解析和编辑固件中的 WSR 压缩数据区域，实现对介质刻录策略参数的精确控制。

### 核心特性

- **双视图模式**
  - 物理表视图：按固件物理表结构显示记录（BD-R、BD-RE、BD-XL 等）
  - 逻辑视图：按 MID（Media ID）分组显示，便于管理同一介质的不同版本

- **完整的 CRUD 操作**
  - 新增记录：前后缀分开输入（各 9 字符），支持从现有记录复制参数模板
  - 编辑记录：独立修改 MID 前缀、后缀和 12 字节参数
  - 删除记录：将记录槽位重置为全 0xFF 空槽
  - 查看详情：显示记录的完整信息（偏移、Excel 类型、速度位等）

- **安全保障**
  - 打开固件时自动验证压缩算法兼容性
  - 不兼容的固件会禁止编辑操作
  - 保存时自动备份原文件为 `.bak`
  - 压缩算法逐字节验证，确保固件完整性

## 技术实现

### 压缩算法

固件 WSR 区域使用自定义 LZSS 变体压缩：
- 滑动窗口：4096 字节
- 匹配长度：3-18 字节
- 距离范围：1-4095
- 特殊规则：最长最远优先、控制字节继承

### 表结构

| 表名 | 起始偏移 | 记录长度 | 槽位数 | 介质类型 |
|------|---------|---------|--------|---------|
| BD-R | 0x0000 | 30B | 64 | BD-R SL 25GB |
| BD-R DL | 0x0780 | 30B | 64 | BD-R DL 50GB |
| BD-RE | 0x0F00 | 30B | 64 | BD-RE SL 25GB |
| BD-RE DL | 0x1680 | 30B | 64 | BD-RE DL 50GB |
| BDXL-R TL | 0x1E00 | 30B | 40 | BD-R TL 100GB |
| BDXL-R QL | 0x2300 | 30B | 40 | BD-R QL 128GB |
| BD-ROM | 0x2800 | 30B | 40 | BD-ROM |
| BD-ROM DL | 0x2D00 | 30B | 40 | BD-ROM DL |
| BD-ROM TL | 0x3200 | 30B | 40 | BD-ROM TL |
| DVD | 0x3700 | 21B | 64 | DVD±R/RW |
| BD-XL | 0x3C00 | 21B | 24 | BD-R/RE XL（混合） |

### 记录格式

**30 字节表（BD-R/RE/ROM）：**
```
[0-8]   MID 前缀（9B，右补空格）
[9-17]  MID 后缀（9B，右补空格）
[18-29] 刻录策略参数（12B）
```

**21 字节表（DVD/BD-XL）：**
```
[0-8]   MID 前缀（9B）
[9-17]  MID 后缀（9B）
[18-20] 参数（3B）
```

## 使用指南

### 环境要求

- Python 3.8 或更高版本
- PyQt6

### 安装依赖

```bash
pip install PyQt6
```

### 启动程序

```bash
python wsrtool_gui.py
```

### 操作流程

#### 1. 打开固件

- 点击"打开固件"按钮
- 选择 `.bin` 格式的固件文件
- 程序会自动检查压缩算法兼容性
- 显示 WSR 区域信息和表结构

#### 2. 查看记录

**物理表视图：**
- 选择物理表（如 BD-R、BD-XL）
- 查看该表的所有记录
- 列显示：序号、状态、MID、参数、Excel类型、速度、偏移

**逻辑视图：**
- 选择 MID 分组
- 查看同一 MID 在不同物理表中的记录
- 便于对比和管理

#### 3. 新增记录

- 在物理表视图点击"新增记录"
- 选择目标空槽
- 输入 MID 前缀（如 `VERBATIMF`）
- 输入 MID 后缀（通常留空或填空格）
- 输入 24 位十六进制参数（如 `000ef0020909300000090000`）
- 或选择参数模板从现有记录复制
- 点击"新增"

#### 4. 编辑记录

- 选中一条有效记录
- 点击"编辑选中记录"
- 修改前缀、后缀或参数
- 点击"保存"

#### 5. 删除记录

- 选中一条有效记录或占位记录
- 点击"删除选中记录"
- 确认删除
- 记录槽位变为全 0xFF 空槽

#### 6. 保存固件

- 修改完成后点击"保存固件"
- 原文件自动备份为 `.bak`
- 新固件写入原文件路径

## 命令行工具

除了 GUI 外，还提供命令行工具 `wsrtool.py`：

```bash
# 查看所有记录
python wsrtool.py a10ame.bin --list

# 查看指定表
python wsrtool.py a10ame.bin --list BD-XL

# 新增记录
python wsrtool.py a10ame.bin --add BD-R "VERBATIMF         " 000ef0020909300000090000

# 编辑记录
python wsrtool.py a10ame.bin --set BD-R 5 "CMCMAGBA5         " 001ef0020909300000090000

# 删除记录
python wsrtool.py a10ame.bin --del BD-RE 10

# 保存到新文件
python wsrtool.py a10ame.bin --save modified.bin
```

## 注意事项

### 兼容性

- ✅ **支持**：LG MT1959 系列固件（如 WH16NS60、BH16NS55）
- ❌ **不支持**：MT1939 系列（使用不同的压缩算法）

### 安全建议

1. **首次使用前备份原固件**
   ```bash
   copy a10ame.bin a10ame.bin.backup
   ```

2. **验证压缩兼容性**
   - 打开固件后查看提示信息
   - "完全匹配"才可编辑
   - "不匹配"的固件会禁止保存

3. **测试刻录**
   - 修改后先用测试盘验证刻录策略
   - 确认无误后再正式使用

4. **保留备份**
   - 程序自动创建 `.bak` 备份
   - 建议额外手动备份到其他位置

### 常见问题

**Q: 为什么我的固件无法编辑？**
A: 程序会检查压缩算法兼容性，如果固件使用了不同的压缩参数，会禁止编辑以防止损坏固件。

**Q: 删除记录后能恢复吗？**
A: 删除操作将槽位填充为 0xFF，无法直接恢复。保存前请确认，或使用 `.bak` 备份恢复。

**Q: MID 前后缀如何填写？**
A: 大多数 MID 只使用前 9 字符（前缀），后缀留空（9 个空格）。如 `VERBATIMF` + 9 个空格。

**Q: 参数含义是什么？**
A: 参数控制刻录策略（功率、速度曲线等），建议从现有记录复制或参考官方数据库。

### 核心类

**Firmware 类（wsrtool.py）：**
```python
class Firmware:
    def __init__(self, path)           # 加载固件
    def records(self, table_name)      # 获取记录列表
    def logical_groups(self)           # 按 MID 分组
    def add_record(self, table, val, slot)     # 新增
    def set_record(self, table, idx, val)      # 编辑
    def delete_record(self, table, idx)        # 删除
    def save(self, inplace=True)       # 保存
```
